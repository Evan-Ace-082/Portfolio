## ✨ Features

- 🌌 **Glassmorphism & Micro-animations**: Premium dark mode UI with interactive radial cursor glow, smooth reveal on scroll, and tilt hover effects.
- ⚡ **Typewriter Hero & Floating Tech Orbit**: Dynamic role transitions and floating badges (JS, React, SQL, C++, Networking).
- 🎓 **Academic Journey & Education**: Interactive vertical timeline showing educational milestones at BUP.
- 🛠️ **Technical Toolkit & Skills**: Categorized skills (Frontend, Backend, Database, Networking, Tools) with visual progress cards.
- 💼 **Project Showcase**: Rich project cards with GitHub links, tech tags, and responsive modal details.
- 🏆 **Achievements & Leadership Timeline**: Filterable cards for leadership positions, technical events, and competitions.
- 🎨 **Hobbies & Beyond Academics**: Creative interests that drive problem-solving.
- 📬 **Interactive Contact System**: Direct messaging and email connectivity with Toast notifications.
- ⚙️ **Admin Panel & Supabase CMS**: Full backend integration for dynamic content management (Projects, Testimonials, Gallery, Blogs, Messages).

## 🚀 Quick Start (Run Locally)

Follow these steps to run the portfolio on your local machine:

### 1. Clone the repository
```bash
git clone https://github.com/Evan-Ace-082/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port shown in terminal) in your browser to view your portfolio!

## 📁 Project Structure

```
├── public/                 # Static assets (favicons, robots.txt)
├── src/
│   ├── assets/             # Images (profile, hero background)
│   ├── components/         # Reusable UI & Admin components
│   │   ├── admin/          # CMS managers & input fields
│   │   └── ui/             # Radix UI primitives
│   ├── integrations/       # Supabase client & authentication
│   ├── lib/                # CMS helper utilities & schemas
│   ├── routes/             # TanStack Start file-based routing
│   │   ├── admin/          # Admin CMS management routes
│   │   └── index.tsx       # Main Portfolio page
│   ├── styles.css          # Core CSS variables & glassmorphism
│   └── start.ts            # TanStack Start entrypoint
├── supabase/               # Database migrations & configuration
├── package.json            # Scripts & dependencies
└── vite.config.ts          # Vite configuration
```

## 🌐 Deploy to Vercel (1-Click)

You can easily host this portfolio for free on [Vercel](https://vercel.com):

1. Go to [Vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **Add New Project** and select `Evan-Ace-082/Portfolio`.
3. Set Framework Preset to **Vite** or **Other**.
4. Click **Deploy**! 🚀
